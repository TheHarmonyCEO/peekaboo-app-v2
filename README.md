## （1）制作アプリのタイト
名前とひらがなを覚える知育アプリ「いないいないばぁ」

## （2）制作アプリの説明（40文字程度）
カーテンを開くと絵文字とひらがなボタンが表示され、ボタンを押すとその絵文字の名前を発話する

## （3）工夫した点・こだわった点
- 前回は技術優先で誰も使わない面白くないアプリを作成してしまったので、今回は使われるアプリを作成すると決めた
- そこでベンチャー・スタートアップのアップのサービス・プロダクトの基本である「1人（n-1）のバーニングニーズを解決し、1人の熱狂的なユーザーをつくる」を目指した
- 身近なバーニングニーズは、「1歳半の娘が1人と時はYouTubeに夢中になってしまうので、これをもっと遊びながら学べるような時間にしたい」という僕のニーズ
- 娘の好きなもの、「・いないいないばぁ、・音楽、・動き」を使った
- スマホでも使えるようにした

## （4）難しかった点・次回トライしたいこと（または機能）
結果、YouTubeには勝てなかった（悔しい）ので、娘がYouTubeより熱狂して学べるアプリを作成したい
